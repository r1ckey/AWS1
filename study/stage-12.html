Amazon EFS (Elastic File System)

  • 共有ストレージ: 複数のEC2（Linux）から同時にマウント可能。
  • スケーリング: 容量を気にせず使えるサーバーレス設計。自動的に拡張。
  • 性能: 数千の接続にも対応可能。

インスタンスが消えてもデータが残るだけでなく、複数のマシンから同じファイルを同時に編集・参照できる、ネットワーク共有フォルダのようなサービスです。Linux環境での共有設定（NFSプロトコル）で利用されます。

Amazon FSx (Windows / Lustre / NetApp)

  • FSx for Windows: ネイティブな Windows ファイルシステム (SMB)。
  • FSx for Lustre: 超高速な並列処理（機械学習やビッグデータ解析）。
  • 完全互換: エンタープライズ向けの既存プロトコルをそのままクラウドへ。

標準的なプロトコル（WindowsならSMB）のままで、非常に高いスループットとIOPSが必要な要件に適しています。特に Lustre は、S3と直接データをやり取りする機能もあり、HPC（ハイパフォーマンスコンピューティング）分野で活躍します。

Storage Gateway

  • ハイブリッド: オンプレミス環境から、シームレスにS3（クラウド）へデータを送る架け橋。
  • 用途: ファイル、ボリューム、テープ（仮想バックアップテープ）の3つのゲートウェイ。

「オンプレミスのデータが多すぎて、一気にクラウドへ移行できない」「一部のデータを手元に置きつつ、残りをS3に保存したい」といったニーズを解決します。既存のアプリ設定を変更することなく、裏側の保存先をAWSに置き換えることができます。

Snowファミリー (物理データ転送)

  • Snowball Edge / Snowcone: ネットワーク経由では時間がかかりすぎる膨大なデータ（ペタバイト級）を、物理デバイスに詰めて送る。
  • Snowmobile: 巨大なコンテナトラック（エクサバイト級）。

「ネットワークを太くするより、トラックに積んで運ぶ方が早い」という物理的な解決策です。強固なセキュリティケースに入った専用端末が送られてくるので、データをコピーしてAWSに送り返します。
